## 🧭 این ریپو چیه؟

اکثر پورتفولیوها شبیه هم تولید شدن. این یکی **عمداً طوری ساخته شده که شبیه اونا نباشه**.

`nomoreidea` گوشه شخصی من از وبه: یک صفحه استاتیک و تک‌صفحه‌ای که ایندکس چیزهایی است که
واقعاً مهندسی‌شون کردم — سیستم‌های امبدد، سخت‌افزار دیجیتال، اپلیکیشن‌های دسکتاپ و پلتفرم‌های تحت وب.
نه عکس استوک، نه آمار جعلی، نه «مورد اعتماد بیش از ۵۰,۰۰۰ تیم». هر عددی که توی این سایت می‌بینید واقعیه
و هر اسکرین‌شاتی از یک ریپویی گرفته شده که خودتون می‌تونید بازش کنید.

سیستم طراحی یک تم تیره اختصاصی است که اسمش رو گذاشتم **Cobalt Night**: یک بوم سرمه‌ای عمیق
(`oklch(16% 0.028 258)`) با ریتم لایه‌لایهٔ باندها، خطوط مویی به جای کارت، و دقیقاً یک رنگ سیگنال —
آبی کوبالت الکتریک — که فقط جایی خرج میشه که معنی داشته باشه.
تایپوگرافی هم Space Grotesk + Inter + JetBrains Mono است.

## 🎨 فلسفه طراحی (قوانین Hallmark)

این پروژه از دکترین ضدِ-قالبیِ [Hallmark](https://github.com/nutlope/hallmark) پیروی می‌کنه:

| اصل | نحوه اجرا در این پروژه |
|---|---|
| **صداقت در محتوا** | صفر آمار جعلی. تعداد ریپوها، دروس و نام همکاران همه با GitHub API زنده راستی‌آزمایی شدن. |
| **توکن‌های قفل‌شده** | هر رنگ و فونتی از متغیرهای CSS نام‌دار در `tokens.css` عبور می‌کنه. صفر مقدار hex درون‌خطی در `site.css`. |
| **عدم بازسازی کروم** | نه نوار مرورگر فیک، نه قاب گوشی فیک، نه پنجره IDE فیک. فقط اسکرین‌شات واقعی داخل `<figure>` با حاشیه مویی. |
| **تنوع ساختاری** | صفحه یک *ایندکس* است، نه قالب پیش‌فرض «هیرو → ۳ کارت فیچر → CTA → فوتر». |
| **کف موبایل** | روی ۳۲۰ / ۳۷۵ / ۴۱۴ / ۷۶۸ / ۱۲۸۰ / ۱۹۲۰ پیکسل با آدیتور خودکار CDP تست شده. |
| **دسترسی‌پذیری** | کنتراست WCAG AA برای تمام جفت‌های متن/پس‌زمینه، حلقه فوکوس مرئی، ناوبری کامل با کیبورد، پشتیبانی reduced-motion. |

## 🛠️ استک فناوری

عمداً ساده. عمداً سریع.

```
HTML5 · CSS3 (متغیرهای سفارشی، فضای رنگ OKLCH، CSS Grid)
صفر فریم‌ورک جاوااسکریپت · صفر Build Step · صفر ردیاب
```

همه‌چیز دو تا فایله: `index.html` و `css/site.css` (+ `css/tokens.css`). همین.
نه React، نه Tailwind، نه Webpack. آنی لود میشه و آفلاین هم کار می‌کنه.

## 🔍 گیت کیفیت خودکار

[`tools/audit.py`](tools/audit.py) رو نوشتم — یک آدیتور headless-Chromium مبتنی بر CDP که صفحه رو
در شش عرض مختلف (۳۲۰ تا ۱۹۲۰ پیکسل) لود می‌کنه و به‌صورت برنامه‌نویسی‌شده بررسی می‌کنه:

- اسکرول افقی در هر ویوپورت
- تارگت‌های لمسی کوچکتر از ۴۴×۴۴ پیکسل (WCAG)
- شکستن متن کلیک‌شونده به دو خط
- خطاهای کنتراست WCAG AA روی هر نود متنی

آخرین اجرا: **TOTAL ISSUES: 0**

```bash
python3 -m http.server 8000
python3 tools/audit.py http://127.0.0.1:8000/index.html
```
