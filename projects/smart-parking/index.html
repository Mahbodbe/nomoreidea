Smart Parking: ESP32 data acquisition and gate control

An end-to-end data acquisition and control system for multi-storey parking: sensors, a PID-controlled barrier gate, two-factor vehicle authentication and a live web dashboard. Built for the Instrumentation and Measurement course at Amirkabir University of Technology.

Stack
ESP32-S3 · C++ · Python · SQLite / PostgreSQL · Chart.js · Proteus
Team
Team project with Erfan Ashkesh and Mani Mohammadi.
Area
Embedded / IoT

What it does

  • Two-factor entry: an RC522 RFID card check combined with licence-plate and colour validation from an ANPR camera.
  • Occupancy sensed twice, with HC-SR04 ultrasonic and A3144 Hall-effect sensors cross-checking each other.
  • Barrier arm driven by a PID-tuned servo, with an IR break-beam as an anti-pinch safety trigger.
  • Nearest-free-slot allocation by floor, backed by a SQLite/PostgreSQL store with local ESP32 buffering for network outages.
  • Dual power path (mains and online UPS) and a Proteus co-simulation linked to the real ESP32 over a virtual serial bridge.
  • Web dashboard with live KPI cards, a 60-slot grid, environmental telemetry charts and access logs, plus a Telegram notification bot.
