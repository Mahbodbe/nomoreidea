Snort 3 & LibDAQ Integration on Windows

A reproducible Windows build and integration environment for Snort 3 and LibDAQ — born out of SCADA intrusion-detection lab work where running modern deep packet inspection natively on Windows workstations mattered.

Stack
Snort 3 · LibDAQ · Npcap · Windows · CMake / MSYS2
Team
Personal systems & security engineering project.
Area
Network Security / IDS

What it does

  • Bridges LibDAQ packet acquisition with Npcap on Windows so Snort 3 can inspect live network interfaces as well as offline PCAP captures.
  • Documents toolchain setup, dependency resolution, and build flags required to compile Snort++ outside Linux.
  • Supports custom protocol inspection rules (such as DNP3 and behavioral thresholds) developed during industrial SCADA security testing.
