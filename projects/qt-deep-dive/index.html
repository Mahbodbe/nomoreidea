Qt Deep Dive: building desktop applications chapter by chapter

An engineering log of learning Qt with C++. It follows the structure of Mastering Qt 5 (2nd edition) and rebuilds each chapter's project with modern C++ idioms and custom dark QSS themes.

Stack
Qt 5/6 · C++17/20 · QSS · SQLite · Qt Charts
Team
Personal learning project.
Area
Desktop software

What it does

  • A ToDo application, a cross-platform system information monitor with Qt Charts, and a gallery application split into a shared core library and a desktop UI.
  • SQLite access through a DAO layer, with model/view classes, proxy models and custom delegates.
  • Safe signal and slot connections, lambda slots and explicit ownership rules.
  • A 14-chapter roadmap with the status of each chapter tracked in the repository README.
