Network Security / IDS

یکپارچه‌سازی و بیلد Snort 3 و LibDAQ روی ویندوز

محیط بیلد و یکپارچه‌سازی تکرارپذیر برای اجرای Snort 3 و LibDAQ روی ویندوز — برگرفته از آزمایشگاه تشخیص نفوذ اسکادا برای زمانی که بازرسی عمیق بسته باید مستقیم در محیط ویندوز اجرا شود.

فناوری‌ها
Snort 3 · LibDAQ · Npcap · Windows · CMake / MSYS2
تیم
پروژه شخصی در حوزه امنیت شبکه و سیستم‌ها.
حوزه
Network Security / IDS

ویژگی‌های کلیدی

  • اتصال لایه دریافت بسته LibDAQ به Npcap در ویندوز برای بازرسی هم‌زمان ترافیک زنده شبکه و فایل‌های PCAP آفلاین.
  • مستندسازی کامل زنجیره ابزارها، وابستگی‌ها و فلگ‌های بیلد برای کامپایل Snort 3 خارج از محیط لینوکس.
  • آماده برای اجرای قواعد سفارشی بازرسی پروتکل‌های صنعتی (مانند DNP3 و آستانه‌های رفتاری) در تست‌های امنیت اسکادا.
